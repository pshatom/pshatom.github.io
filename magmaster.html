MagMaster Dataset

This interface provides an interactive visualization of the MagMaster Dataset, which integrates large-scale DFT calculations with machine learning to map the structural properties of binary magnesium compounds.

If you find this dataset useful in your research, please cite the following publication:

Sharma, P., Akram, B., Bannerjee, T., Singh, P., & Balasubramanian, G. (2025). MagMaster: Mapping structural properties of binary magnesium compounds using accurate large-scale DFT and machine learning integration.
